# Friend-dex
a digital pokedex but for my friends!

- inspiration from the pokedex from Pokemon
- made in html, css, js

### how to use?
- go to [https://frienddex.vercel.app/](https://frienddex.vercel.app/)
- click on naviagtion buttons to move to next and previous cards
- add cards by clicking on the + button
- set name, type (it could be your skill/hobby), evolution age (your age) and a fun fact

### features
- lights in the pokedex
- custom display filter for images
- linked to firebase
- buttons for navigation and adding friends!
